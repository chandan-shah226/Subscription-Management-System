# Subscription Management System

## Introduction

The **Subscription Management System** is a web-based application designed to simplify and streamline the management of subscription-based businesses.

The system aims to bring essential business operations—including product and plan management, quotations, subscriptions, invoicing, billing, discounts, payments, and financial reporting—into a unified platform.

It is being developed to reduce manual work, improve data management, track subscription lifecycles, and provide better visibility into business operations.

**Technology Stack:** Python, Flask, SQLite, SQLAlchemy, Flask-JWT-Extended, HTML, CSS, and JavaScript.

## Project Status

This project is currently under development as part of a team-based software development initiative. Features and modules are being implemented progressively.
